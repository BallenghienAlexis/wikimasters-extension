# Politique de sécurité

WM Collection est une extension Chrome personnelle, non affiliée à WikiMasters.

## Signaler une vulnérabilité
Ne crée **pas** d'issue publique. Utilise « Report a vulnerability » dans l'onglet *Security* du dépôt (signalement privé). Indique ce qui est touché, comment le reproduire et l'effet possible. Une première réponse est visée sous 7 jours.

## Ne publie jamais
Jeton de session, cookie, clé d'API ou donnée réelle de ton compte WikiMasters, dans une issue, une PR ou une capture.

## Périmètre
Dernière version de `main` uniquement.
